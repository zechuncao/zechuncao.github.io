Probability of an Event

Pierre-Simon Laplace (1749–1827) first developed a classical theory of probability in the 18th century, when he analyzed games of chance.

Key terms:

  • An experiment is a procedure that yields one of a given set of possible outcomes.
  • The sample space of the experiment is the set of possible outcomes.
  • An event is a subset of the sample space.

Probability of an Event

Definition (Laplace): If \(S\) is a finite sample space of equally likely outcomes, and \(E\) is an event, that is, a subset of \(S\), then the probability of \(E\) is

\[p(E) = \frac{|E|}{|S|}.\]

For every event \(E\) we have \(0 \leq p(E) \leq 1\), since \(0 \leq |E| \leq |S|\).

Applying Laplace’s Definition

Example: An urn contains \(4\) blue balls and \(5\) red balls. What is the probability that a ball chosen from the urn is blue?

Solution: There are \(9\) equally likely outcomes and \(4\) produce a blue ball, so \(p(\text{blue}) = 4/9\).

Example: What is the probability that when two dice are rolled, the sum of the numbers on the two dice is \(7\)?

Solution: By the product rule there are \(6^2 = 36\) equally likely outcomes. Six of these sum to \(7\), so

\[p(\text{sum}=7) = \frac{6}{36} = \frac{1}{6}.\]

Applying Laplace’s Definition

Example: In a lottery, a player wins the large prize by picking four digits that match, in correct order, four digits selected by a random mechanical process. What is the probability of winning?

Solution: By the product rule there are \(10^4 = 10{,}000\) ways to pick four digits. Only one is correct, so

\[p(\text{large prize}) = \frac{1}{10{,}000} = 0.0001.\]

Applying Laplace’s Definition

Example (continued): A smaller prize is won if exactly three of the four digits match. What is the probability of winning a small prize?

Solution: For the one wrong digit there are \(9\) choices and \(4\) positions, giving \(36\) ways, so

\[p(\text{small prize}) = \frac{36}{10{,}000} = \frac{9}{2500} = 0.0036.\]

Applying Laplace’s Definition

Example: What is the probability that a person picks the correct six numbers out of \(40\)?

Solution: The number of ways to choose six numbers out of \(40\) is

\[C(40,6) = \frac{40!}{34!\,6!} = 3{,}838{,}380.\]

Hence the probability of picking the winning combination is

\[\frac{1}{3{,}838{,}380} \approx 0.00000026.\]

Applying Laplace’s Definition

Example: What is the probability that the numbers \(11, 4, 17, 39, 23\) are drawn in that order from a bin with \(50\) balls labeled \(1, 2, \ldots, 50\) if

  1. the ball selected is not returned to the bin?
  2. the ball selected is returned before the next draw?

Solution:

  1. Without replacement: \(50 \cdot 49 \cdot 48 \cdot 47 \cdot 46 = 254{,}251{,}200\) ordered sequences, so \(p = 1/254{,}251{,}200\).
  2. With replacement: \(50^5 = 312{,}500{,}000\) sequences, so \(p = 1/312{,}500{,}000\).

Complements of Events

Theorem 1: Let \(E\) be an event in sample space \(S\). Let \(\overline{\!E\!} = S - E\) be the complementary event. Then

\[p(\overline{\!E\!}) = 1 - p(E).\]

Proof: \(p(\overline{\!E\!}) = \dfrac{|S| - |E|}{|S|} = 1 - \dfrac{|E|}{|S|} = 1 - p(E).\)

Complement Example

Example: A sequence of \(10\) bits is chosen randomly. What is the probability that at least one of these bits is \(0\)?

Solution: Let \(E\) be the event that at least one of the \(10\) bits is \(0\). Then \(\overline{\!E\!}\) is the event that all bits are \(1\). The sample space has size \(2^{10} = 1024\), and \(|\overline{\!E\!}| = 1\), so

\[p(E) = 1 - p(\overline{\!E\!}) = 1 - \frac{1}{1024} = \frac{1023}{1024}.\]

Union of Two Events

Theorem 2: Let \(E_1\) and \(E_2\) be events in sample space \(S\). Then

\[p(E_1 \cup E_2) = p(E_1) + p(E_2) - p(E_1 \cap E_2).\]

Proof: By inclusion–exclusion, \(|E_1 \cup E_2| = |E_1| + |E_2| - |E_1 \cap E_2|\). Divide by \(|S|\).

Union Example

Example: What is the probability that a positive integer selected at random from \(\{1, 2, \ldots, 100\}\) is divisible by either \(2\) or \(5\)?

Solution: Let \(E_1\) be divisible by \(2\) and \(E_2\) be divisible by \(5\). Then

\[|E_1| = 50,\quad |E_2| = 20,\quad |E_1 \cap E_2| = 10.\]

\[p(E_1 \cup E_2) = \frac{50}{100} + \frac{20}{100} - \frac{10}{100} = \frac{60}{100} = \frac{3}{5}.\]

Assigning Probabilities

Laplace’s definition assumes that all outcomes are equally likely. We now drop that restriction.

Let \(S\) be a sample space of an experiment with finitely (or countably) many outcomes. We assign a probability \(p(s)\) to each outcome \(s \in S\) such that

\[0 \le p(s) \le 1 \quad \text{for each } s \in S, \qquad \sum_{s \in S} p(s) = 1.\]

The function \(p\) is called a probability distribution on \(S\).

Assigning Probabilities

Example: Assign probabilities to \(H\) (heads) and \(T\) (tails) for a fair coin, and for a coin biased so that heads comes up twice as often as tails.

Solution: For a fair coin, \(p(H) = p(T) = 1/2\).

For the biased coin, \(p(H) = 2\,p(T)\). Since \(p(H) + p(T) = 1\),

\[3\,p(T) = 1 \implies p(T) = \frac{1}{3},\; p(H) = \frac{2}{3}.\]

Uniform Distribution

Definition: Suppose \(S\) is a set with \(n\) elements. The uniform distribution assigns probability \(1/n\) to each element of \(S\). (This recovers Laplace’s definition.)

Example: For a fair coin, \(p(H) = p(T) = 1/2\).

Probability of an Event

Definition: The probability of an event \(E\) is the sum of the probabilities of the outcomes in \(E\):

\[p(E) = \sum_{s \in E} p(s).\]

No assumption is made about the distribution.

Example

Example: A die is biased so that \(3\) appears twice as often as each other number, and the other five outcomes are equally likely. What is the probability that an odd number appears?

Solution: We want \(p(E)\) for \(E = \{1, 3, 5\}\). Since \(p(3) = 2p(k)\) for \(k \ne 3\) and the total is \(1\),

\[p(3) = \frac{2}{7},\quad p(1) = p(2) = p(4) = p(5) = p(6) = \frac{1}{7}.\]

\[p(E) = p(1) + p(3) + p(5) = \frac{1}{7} + \frac{2}{7} + \frac{1}{7} = \frac{4}{7}.\]

Complements and Unions (General)

Complement: \[p(\overline{\!E\!}) = 1 - p(E).\]

Union: \[p(E_1 \cup E_2) = p(E_1) + p(E_2) - p(E_1 \cap E_2).\]

Both formulas carry over from the equally-likely case.

Combinations of Events

Theorem: If \(E_1, E_2, \ldots\) is a sequence of pairwise disjoint events in sample space \(S\), then

\[p\!\left(\bigcup_{i} E_i\right) = \sum_{i} p(E_i).\]

Conditional Probability

Definition: Let \(E\) and \(F\) be events with \(p(F) > 0\). The conditional probability of \(E\) given \(F\) is

\[p(E \mid F) = \frac{p(E \cap F)}{p(F)}.\]

Conditional Probability Example

Example: A bit string of length four is generated at random (each of the \(16\) strings equally likely). What is the probability that it contains at least two consecutive \(0\)s, given that its first bit is a \(0\)?

Solution: Let \(E\) be “at least two consecutive \(0\)s” and \(F\) be “first bit is \(0\).” Then

\[E \cap F = \{0000, 0001, 0010, 0011, 0100\},\quad p(E \cap F) = \tfrac{5}{16}.\]

\[p(F) = \tfrac{8}{16} = \tfrac{1}{2}.\]

\[p(E \mid F) = \frac{5/16}{1/2} = \frac{5}{8}.\]

Conditional Probability Example

Example: A family has two children. Assuming \(BB\), \(BG\), \(GB\), \(GG\) are equally likely, what is the probability of two boys given at least one boy?

Solution: \(E = \{BB\}\), \(F = \{BB, BG, GB\}\), \(E \cap F = \{BB\}\). So \(p(F) = 3/4\) and \(p(E \cap F) = 1/4\).

\[p(E \mid F) = \frac{1/4}{3/4} = \frac{1}{3}.\]

Independence

Definition: The events \(E\) and \(F\) are independent if and only if

\[p(E \cap F) = p(E)\,p(F).\]

Independence Example

Example: \(E\) = bit string of length \(4\) begins with \(1\); \(F\) = bit string contains an even number of \(1\)s. Are \(E\) and \(F\) independent?

Solution: There are \(8\) strings starting with \(1\) and \(8\) with an even number of \(1\)s:

\[p(E) = p(F) = \frac{8}{16} = \frac{1}{2}.\]

\(E \cap F = \{1111, 1100, 1010, 1001\}\), so \(p(E \cap F) = 4/16 = 1/4\).

Since \(p(E)\,p(F) = 1/4 = p(E \cap F)\), the events are independent.

Independence Example

Example: \(E\) = two boys, \(F\) = at least one boy. Are \(E\) and \(F\) independent?

Solution: \(p(E) = 1/4\), \(p(F) = 3/4\), \(p(E \cap F) = 1/4\).

\[p(E)\,p(F) = \frac{1}{4} \cdot \frac{3}{4} = \frac{3}{16} \ne \frac{1}{4} = p(E \cap F).\]

So \(E\) and \(F\) are not independent.

Pairwise and Mutual Independence

Definition: Events \(E_1, E_2, \ldots, E_n\) are pairwise independent iff

\[p(E_i \cap E_j) = p(E_i)\,p(E_j) \quad \text{for all } 1 \le i < j \le n.\]

They are mutually independent iff for every choice of \(2 \le m \le n\) and indices \(1 \le i_1 < i_2 < \cdots < i_m \le n\),

\[p(E_{i_1} \cap E_{i_2} \cap \cdots \cap E_{i_m}) = p(E_{i_1})\,p(E_{i_2}) \cdots p(E_{i_m}).\]

Bernoulli Trials

James Bernoulli (1654–1705)

Definition: An experiment with exactly two possible outcomes (e.g., flipping a coin) is a Bernoulli trial. One outcome is called a success, the other a failure. If \(p\) is the probability of success and \(q\) of failure, then \(p + q = 1\).

Many problems ask for the probability of exactly \(k\) successes in \(n\) mutually independent Bernoulli trials.

Bernoulli Trials

Example: A coin is biased so that \(p(H) = 2/3\). What is the probability that exactly four heads occur in seven flips?

Solution: There are \(2^7 = 128\) outcomes. The number of ways to pick which \(4\) of the \(7\) flips are heads is \(C(7, 4)\). Each such outcome has probability \((2/3)^4 (1/3)^3\). Hence

\[C(7, 4)\,\left(\tfrac{2}{3}\right)^{\!4}\!\left(\tfrac{1}{3}\right)^{\!3} = \frac{35 \cdot 16}{2187} = \frac{560}{2187}.\]

Binomial Distribution

Theorem 2: The probability of exactly \(k\) successes in \(n\) independent Bernoulli trials, with probability of success \(p\) and failure \(q = 1 - p\), is

\[b(k; n, p) = C(n, k)\,p^{k}\,q^{n-k}.\]

Proof sketch: Each length-\(n\) sequence with \(k\) successes and \(n-k\) failures has probability \(p^k q^{n-k}\). There are \(C(n, k)\) such sequences.

Viewed as a function of \(k\), \(b(k; n, p)\) is the binomial distribution.

Random Variables

Definition: A random variable is a function from the sample space of an experiment to the set of real numbers. It assigns a real number to each possible outcome.

A random variable is a function — it is not a variable, and it is not random.

Random Variables

Definition: The distribution of a random variable \(X\) on a sample space \(S\) is the set of pairs \((r, p(X = r))\) for all \(r \in X(S)\), where \(p(X = r)\) is the probability that \(X\) takes the value \(r\).

Example: Flip a fair coin \(3\) times and let \(X\) be the number of heads. Each of the \(8\) outcomes has probability \(1/8\), so

\[p(X = 0) = \tfrac{1}{8},\quad p(X = 1) = \tfrac{3}{8}, \quad p(X = 2) = \tfrac{3}{8},\quad p(X = 3) = \tfrac{1}{8}.\]

The Birthday Problem

How many people must be in a room so that the probability that at least two share a birthday exceeds \(1/2\)?

Assume \(366\) equally likely birthdays. Let \(p_n\) be the probability that \(n\) people all have different birthdays:

\[p_n = \frac{365}{366} \cdot \frac{364}{366} \cdots \frac{367 - n}{366}.\]

The probability of a shared birthday is \(1 - p_n\).

Birthday Problem — Numerical

  • \(n = 22\): \(1 - p_n \approx 0.457\)
  • \(n = 23\): \(1 - p_n \approx 0.506\)

So \(\mathbf{23}\) people are enough for the probability of a shared birthday to exceed \(1/2\).

Monte Carlo Algorithms

Algorithms that make random choices at one or more steps are called probabilistic algorithms.

Monte Carlo algorithms are probabilistic algorithms for decision problems (answer is true or false). The algorithm runs a sequence of tests; each test responds true or unknown.

  • If any test returns true, the algorithm halts and outputs true.
  • If every test in the sequence returns unknown, the algorithm outputs false.

The algorithm may output false when the true answer is true, but that probability can be made very small with enough tests.

Probabilistic Primality Testing

Used in finding large primes for RSA (Chapter 4).

An integer \(n > 1\) can be shown composite if it fails Miller’s test for a random base \(b\) with \(1 < b < n\). If \(n\) passes the test, it may be prime or composite.

The probability that a composite \(n\) passes Miller’s test for a random \(b\) is less than \(1/4\).

Run the test \(k\) times with independent random bases. If \(n\) passes all \(k\) times, the probability that \(n\) is composite is at most \((1/4)^k\). With \(k = 10\), this is less than \(1\) in \(10^6\).

Motivation for Bayes’ Theorem

Bayes’ theorem lets us use probability to answer questions such as:

  • Given that someone tests positive for a disease, what is the probability that they actually have it?
  • Given that someone tests negative, what is the probability that they do have it?

Applications span medicine, law, artificial intelligence, engineering, and many other fields.

Bayes’ Theorem

Thomas Bayes (1702–1761)

Bayes’ Theorem: Suppose \(E\) and \(F\) are events from a sample space \(S\) with \(p(E) \ne 0\) and \(p(F) \ne 0\). Then

\[p(F \mid E) = \frac{p(E \mid F)\,p(F)} {p(E \mid F)\,p(F) + p(E \mid \overline{\!F\!})\,p(\overline{\!F\!})}.\]

Bayes’ Theorem — Example

Example: Box 1 contains \(2\) green and \(7\) red balls. Box 2 contains \(4\) green and \(3\) red. Bob picks a box at random, then a ball at random from that box. Given that the ball is red, what is the probability that he picked Box 1?

Let \(E\) = “ball is red,” \(F\) = “picked Box 1.”

\[p(F) = p(\overline{\!F\!}) = \tfrac{1}{2},\quad p(E \mid F) = \tfrac{7}{9},\quad p(E \mid \overline{\!F\!}) = \tfrac{3}{7}.\]

\[p(F \mid E) = \frac{(7/9)(1/2)}{(7/9)(1/2) + (3/7)(1/2)} = \frac{7/18}{7/18 + 3/14} = \frac{49}{76}.\]

Derivation of Bayes’ Theorem

Recall the definition of conditional probability:

\[p(E \mid F) = \frac{p(E \cap F)}{p(F)}.\]

Solving for the intersection:

\[p(E \cap F) = p(E \mid F)\,p(F).\]

Derivation of Bayes’ Theorem

By symmetry,

\[p(E \cap F) = p(F \mid E)\,p(E).\]

Equating the two expressions for \(p(E \cap F)\):

\[p(F \mid E)\,p(E) = p(E \mid F)\,p(F).\]

Solving for \(p(F \mid E)\) gives

\[p(F \mid E) = \frac{p(E \mid F)\,p(F)}{p(E)}.\]

Derivation of Bayes’ Theorem

To express \(p(E)\) without referring to \(F \cap E\) directly, condition on whether \(F\) occurs:

\[p(E) = p(E \mid F)\,p(F) + p(E \mid \overline{\!F\!})\,p(\overline{\!F\!}).\]

Substituting gives the statement of Bayes’ theorem.

Applying Bayes’ Theorem

Example: One person in \(100{,}000\) has a particular disease. A test gives:

  • a positive result \(99\%\) of the time when given to someone with the disease;
  • a negative result \(99.5\%\) of the time when given to someone without it.

Find:

  1. the probability that a person who tests positive has the disease;
  2. the probability that a person who tests negative does not have the disease.

Should someone who tests positive be worried?

Applying Bayes’ Theorem

Let \(D\) = “has the disease,” \(E\) = “tests positive.”

\[p(D) = 10^{-5},\; p(\overline{\!D\!}) = 1 - 10^{-5},\; p(E \mid D) = 0.99,\; p(E \mid \overline{\!D\!}) = 0.005.\]

\[p(D \mid E) = \frac{p(E \mid D)\,p(D)} {p(E \mid D)\,p(D) + p(E \mid \overline{\!D\!})\,p(\overline{\!D\!})}\]

\[= \frac{(0.99)(10^{-5})} {(0.99)(10^{-5}) + (0.005)(1 - 10^{-5})} \approx 0.002.\]

Even after a positive test, the chance of having the disease is only about \(0.2\%\).

Applying Bayes’ Theorem

What if the result is negative?

\[p(\overline{\!D\!} \mid \overline{\!E\!}) = \frac{p(\overline{\!E\!} \mid \overline{\!D\!})\,p(\overline{\!D\!})} {p(\overline{\!E\!} \mid \overline{\!D\!})\,p(\overline{\!D\!}) + p(\overline{\!E\!} \mid D)\,p(D)}\]

\[= \frac{(0.995)(1 - 10^{-5})} {(0.995)(1 - 10^{-5}) + (0.01)(10^{-5})} \approx 0.9999999.\]

So a negative test almost certainly means the disease is absent.

Generalized Bayes’ Theorem

Generalized Bayes’ Theorem: Suppose \(E\) is an event and \(F_1, F_2, \ldots, F_n\) are mutually exclusive events with \(\bigcup_{i=1}^{n} F_i = S\), and \(p(F_i) \ne 0\) for \(i = 1, \ldots, n\). Then for each \(j\),

\[p(F_j \mid E) = \frac{p(E \mid F_j)\,p(F_j)} {\displaystyle\sum_{i=1}^{n} p(E \mid F_i)\,p(F_i)}.\]

Bayesian Spam Filters

Given an initial set \(B\) of spam messages and a set \(G\) of non-spam messages, we can predict whether a new message is spam.

For a word \(w\), let \(n_B(w)\) and \(n_G(w)\) be the number of messages in \(B\) and \(G\) containing \(w\).

Estimated probability a spam message contains \(w\):

\[p(w) = \frac{n_B(w)}{|B|}.\]

Estimated probability a non-spam message contains \(w\):

\[q(w) = \frac{n_G(w)}{|G|}.\]

Bayesian Spam Filters

Let \(S\) = “message is spam” and \(E\) = “message contains \(w\).” By Bayes’ theorem,

\[p(S \mid E) = \frac{p(E \mid S)\,p(S)} {p(E \mid S)\,p(S) + p(E \mid \overline{\!S\!})\,p(\overline{\!S\!})}.\]

Assuming \(p(S) = p(\overline{\!S\!}) = 1/2\) and substituting \(p(E \mid S) \approx p(w)\), \(p(E \mid \overline{\!S\!}) \approx q(w)\):

\[r(w) = \frac{p(w)}{p(w) + q(w)}.\]

Classify the message as spam if \(r(w)\) exceeds a threshold.

Bayesian Spam Filters — Example

Example: The word Rolex occurs in \(250\) of \(2000\) spam messages and in \(5\) of \(1000\) non-spam messages. Use threshold \(0.9\).

\[p(\text{Rolex}) = \frac{250}{2000} = 0.125,\quad q(\text{Rolex}) = \frac{5}{1000} = 0.005.\]

\[r(\text{Rolex}) = \frac{0.125}{0.125 + 0.005} = \frac{0.125}{0.130} \approx 0.962.\]

Since \(0.962 > 0.9\), classify as spam and reject.

Spam Filters — Multiple Words

Accuracy improves by considering more than one word.

Let \(E_1, E_2\) be the events that the message contains words \(w_1, w_2\). Assume the events are independent and \(p(S) = 1/2\). Then

\[r(w_1, w_2) = \frac{p(w_1)\,p(w_2)} {p(w_1)\,p(w_2) + q(w_1)\,q(w_2)}.\]

Spam Filters — Multiple Words

Example: \(2000\) spam and \(1000\) non-spam messages. The word stock occurs in \(400\) spam and \(60\) non-spam; undervalued occurs in \(200\) spam and \(25\) non-spam.

\[p(\text{stock}) = 0.2,\; q(\text{stock}) = 0.06,\; p(\text{under.}) = 0.1,\; q(\text{under.}) = 0.025.\]

\[r = \frac{(0.2)(0.1)}{(0.2)(0.1) + (0.06)(0.025)} = \frac{0.02}{0.02 + 0.0015} \approx 0.930.\]

With threshold \(0.9\), classify as spam.

Spam Filters — Multiple Words

In general, with \(k\) independent words \(w_1, \ldots, w_k\),

\[r(w_1, \ldots, w_k) = \frac{\prod_{i=1}^{k} p(w_i)} {\prod_{i=1}^{k} p(w_i) + \prod_{i=1}^{k} q(w_i)}.\]

The more words considered, the more accurate the filter. Accuracy can be further improved by treating word pairs or certain strings as single features.
